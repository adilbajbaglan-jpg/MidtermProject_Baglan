About BagaShop

BagaShop is a student project about a small online store. The idea is to make shopping simple and clear. The store focuses on useful everyday products with understandable prices. The design uses basic colors and layouts so the pages are easy to read.

Project steps

  1. Choose the store idea
  2. Create the page structure
  3. Add products and prices
  4. Make the pages responsive
  5. Test the navigation

Store facts

  • Four main pages
  • Prices shown in KZT
  • Responsive layout
  • Simple student design
